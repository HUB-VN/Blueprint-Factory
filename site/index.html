Blog kiến trúc thông thường cho bạn kiến thức. Blueprint Factory cho bạn thêm một thứ nữa: thời gian — vì tài liệu ở đây là đầu vào trực tiếp cho quy trình AI của bạn, không chỉ là bài đọc.

Human Edition

Để hiểu và ra quyết định

Bộ tài liệu HTML dàn trang chuẩn xuất bản — đọc trên web, in được, chia sẻ được cho team và stakeholder.

  • Whitepaper triết lý thiết kế
  • BRD — đặc tả nghiệp vụ đầy đủ gate & luồng
  • Solution Architecture + Capability Spec
  • Policy Matrix + Runbook vận hành
Agent Pack

Để AI agent thực thi

Cùng nội dung đó, ở dạng máy dùng được: YAML/JSON có ID chuẩn, decision table, tham số chờ điền — thả vào Claude Code / Cursor là bắt đầu.

  • CLAUDE.md — file mồi: thứ tự đọc, điều phải hỏi
  • journey.yaml · services.yaml · policies.yaml…
  • Guides riêng cho coding / business / product agent
  • manifest.json — checksum, version, validate được
Phép thử của mỗi bản phát hành: nạp Agent Pack vào một coding agent sạch và yêu cầu scaffold hệ thống — đạt chuẩn khi agent không phải hỏi lại bất kỳ điều gì blueprint đã trả lời.
