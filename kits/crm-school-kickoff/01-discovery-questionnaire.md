# 01 · Bộ câu hỏi Discovery

**Giai đoạn:** Trước kickoff (T-6 → T-3 tuần) · **Chủ trì:** BA · **Thời lượng:** 5–7 buổi phỏng vấn, mỗi buổi 60–90 phút
**Mục tiêu:** hiểu cách trường *thực sự* tuyển sinh hôm nay (không phải cách sơ đồ tổ chức mô tả), để kickoff bàn về quyết định chứ không bàn về thông tin cơ bản.

---

## 0. Nguyên tắc phỏng vấn

1. **Hỏi về hành vi, không hỏi về mong muốn.** "Lần gần nhất có phụ huynh gọi hotline lúc 21h, chuyện gì xảy ra?" tốt hơn "Anh/chị muốn CRM làm gì?".
2. **Xin xem màn hình thật.** File Excel tuyển sinh, nhóm Zalo nội bộ, sổ đăng ký sự kiện. Chụp lại (được phép) — đó là dữ liệu cho doc 05.
3. **Một buổi một nhóm vai trò.** Không phỏng vấn tư vấn viên cùng trưởng phòng — họ sẽ nói khác nhau, và cả hai đều cần nghe.
4. **Ghi lại số thật kèm nguồn.** "Khoảng 3.000 lead/năm (theo chị Lan, Trưởng TS, ước tính)" ≠ "3.000 lead/năm (đếm từ Excel 2025–2026)".

## 1. Lịch phỏng vấn đề xuất

| Buổi | Đối tượng | Trọng tâm | Phần câu hỏi |
|---|---|---|---|
| S1 | Hiệu trưởng / HĐQT (Sponsor) | Chiến lược, chỉ tiêu, định nghĩa thành công | §2 |
| S2 | Trưởng phòng Tuyển sinh | Quy trình, chỉ tiêu, đội ngũ, chính sách ưu đãi | §3, §4 |

## 2. Ban giám hiệu / Sponsor

**Chiến lược & mục tiêu**
1. Chỉ tiêu tuyển sinh lớp 10 năm học tới là bao nhiêu? Năm nay đạt bao nhiêu % chỉ tiêu? [ĐIỀN]
2. Tỷ trọng doanh thu: khoá dài hạn / khoá ngắn hạn / khác? Kỳ vọng 3 năm tới thay đổi thế nào?
3. Ba lý do lớn nhất khiến trường *mất* học sinh vào tay đối thủ? Đối thủ chính là ai (trường tư khác, công lập chất lượng cao, quốc tế)?
4. Nếu sau 12 tháng dự án CRM được coi là thành công, anh/chị sẽ nhìn thấy điều gì? (Ép về 3 chỉ số.)
5. Anh/chị cần xem báo cáo nào, tần suất nào, trên thiết bị nào?

**Quyền quyết định**
6. Ai có quyền duyệt học bổng / ưu đãi / giảm học phí? Có ngưỡng theo % hoặc theo số tiền không? → tham số `P-08` của BP-01
7. Ai là người chốt cuối cùng khi Tuyển sinh và Marketing bất đồng (ví dụ về chất lượng lead)?
8. Ngân sách dự án đã được phê duyệt chưa? Gồm license, triển khai, tích hợp, đào tạo?

**Rủi ro & ràng buộc**
9. Có mốc nào dự án **tuyệt đối** không được ảnh hưởng không (Open Day tháng X, đợt nhận hồ sơ…)?
10. Đã từng triển khai CRM/phần mềm nào thất bại chưa? Vì sao?

## 3. Trưởng phòng Tuyển sinh — quy trình & quản lý

**Quy trình hiện tại** (vẽ cùng người được phỏng vấn trên bảng trắng)
1. Một lead đi từ "lần đầu biết đến trường" đến "nộp tiền giữ chỗ" qua những bước nào? Bước nào hay tắc nhất?
2. Lead được chia cho tư vấn viên thế nào? Theo khu vực, trường THCS nguồn, xoay vòng, hay ai nghe máy trước được?
3. Có bài kiểm tra đầu vào / phỏng vấn / xét học bạ không? Ai chấm, kết quả lưu ở đâu?
4. Có các đợt tuyển sinh (sớm / chính thức / bổ sung) không? Điều kiện và ưu đãi mỗi đợt khác nhau thế nào?
5. Phụ huynh "chờ kết quả thi công lập rồi mới quyết" chiếm khoảng bao nhiêu %? Trường xử lý nhóm này thế nào? (Thường tạo đỉnh tuyển sinh thứ hai sau khi có điểm thi vào 10.)
6. Giữ chỗ / đặt cọc: bao nhiêu tiền, có hoàn không, điều kiện hoàn? [ĐIỀN]
7. Tái ghi danh học sinh hiện hữu (lớp 10 → 11 → 12) có quy trình riêng không? Tỷ lệ rời trường mỗi năm?
8. Chuyển trường giữa năm: bao nhiêu hồ sơ/năm, ai xử lý?

**Đội ngũ & đo lường**
9. Đội tư vấn bao nhiêu người, ca làm việc, có làm cuối tuần/tối không?
10. Chỉ tiêu cá nhân được giao thế nào? Có thưởng theo số nhập học không? (Ảnh hưởng đến quy tắc gán lead và ghi nhận công — rất nhạy cảm.)
11. Hiện đo hiệu suất tư vấn viên bằng gì? Ai tổng hợp, mất bao lâu?
12. Lý do thua phổ biến nhất? Có đang ghi lại không?

## 4. Tư vấn viên tuyển sinh — một ngày làm việc

1. Kể lại ngày hôm qua từ lúc đến trường: anh/chị mở những ứng dụng nào, theo thứ tự nào?
2. Lead mới đến với anh/chị qua đâu? (Zalo cá nhân, nhóm Zalo nội bộ, Excel chung, Facebook Page inbox, hotline chuyển máy…)
3. Anh/chị nhớ ai cần gọi lại hôm nay bằng cách nào?
4. Khi phụ huynh gọi lại sau 2 tháng, anh/chị có biết lần trước đã nói gì không? Tìm ở đâu?
5. Phụ huynh hỏi gì nhiều nhất? Câu nào khó trả lời nhất? (→ đầu vào cho doc 11)
6. Anh/chị dùng **Zalo cá nhân** nói chuyện với phụ huynh không? Nếu nghỉ việc, các cuộc hội thoại đó đi đâu? *(Câu hỏi then chốt — rủi ro mất dữ liệu và tuân thủ.)*
7. Có trường hợp hai tư vấn viên cùng gọi một phụ huynh không? Xử lý thế nào?
8. Nếu được bỏ một việc tay chân, anh/chị bỏ việc gì?

## 5. Marketing — kênh & đo lường

1. Liệt kê toàn bộ kênh tạo lead hiện có, ước lượng lead/tháng và chi phí/tháng từng kênh:

   | Kênh | Lead/tháng | Chi phí/tháng | Ai quản lý | Lead đi về đâu |
   |---|---|---|---|---|
   | Facebook / Meta Lead Ads | | | | |
   | Fanpage inbox / Messenger | | | | |
   | Zalo OA | | | | |
   | TikTok | | | | |
   | Google Ads / SEO website | | | | |
   | Form website | | | | |
   | Hotline / tổng đài | | | | |
   | Walk-in (đến trực tiếp) | | | | |
   | Giới thiệu từ phụ huynh hiện hữu | | | | |
   | Trường THCS đối tác / giáo viên giới thiệu | | | | |
   | Sự kiện (xem §6) | | | | |
   | Khác: [ĐIỀN] | | | | |

2. Hiện có biết **chi phí trên mỗi học sinh nhập học** theo kênh không? Nếu không, thiếu mắt xích nào?
3. Có dùng UTM / mã nguồn không? Quy ước đặt tên chiến dịch thế nào?
4. Lead từ quảng cáo bao lâu thì đến tay tư vấn viên? Có ai kiểm tra lead rác không?
5. Gửi tin cho phụ huynh bằng gì? (Zalo ZNS, SMS brandname, email, nhóm Zalo lớp…) Có danh sách từ chối nhận tin không?
6. Nội dung nuôi dưỡng (nurture) đang có: bài viết, video, brochure, học bổng, bảng học phí?
7. Có phân khúc phụ huynh không (khu vực, thu nhập, mục tiêu du học, học lực con)?

## 6. Sự kiện

1. Danh sách sự kiện trong năm, quy mô, mục đích:

   | Sự kiện | Tháng | Số đăng ký | Số tham dự | Mục đích (lead mới / chốt / giữ chân) |
   |---|---|---|---|---|
   | Open Day / Ngày hội tuyển sinh | | | | |
   | Hội thảo phụ huynh (định hướng, du học…) | | | | |
   | Thi thử vào 10 | | | | |
   | "Một ngày làm học sinh" / trải nghiệm | | | | |
   | Tham quan trường (campus tour) cá nhân | | | | |
   | Sự kiện tại trường THCS đối tác | | | | |
   | Khác: [ĐIỀN] | | | | |

2. Đăng ký sự kiện bằng gì (Google Form, form web, gọi điện)? Check-in thế nào?
3. Tỷ lệ "đăng ký nhưng không đến" khoảng bao nhiêu? Có nhắc lịch không, bằng kênh gì, trước bao lâu?
4. Sau sự kiện, bao lâu thì tư vấn viên liên hệ người tham dự? Ai chịu trách nhiệm?
5. Có đo được bao nhiêu học sinh nhập học đến từ từng sự kiện không?
6. Kết quả thi thử được trả cho phụ huynh thế nào? (Đây là "lý do chính đáng" để liên hệ lại — điểm chạm vàng.)

## 7. Khoá ngắn hạn

1. Danh mục khoá: tên, đối tượng (học sinh trong trường / ngoài trường), thời lượng, học phí, sĩ số tối đa. [ĐIỀN]
2. Đăng ký và thanh toán thế nào? Có thanh toán online không?
3. Học sinh **ngoài trường** học khoá ngắn hạn (ví dụ lớp 8–9 học trại hè) có được chuyển cho đội tuyển sinh lớp 10 không? *(Cơ hội cross-sell lớn nhất, thường bị bỏ sót.)*
4. Có danh sách chờ khi lớp đầy không? Có huỷ lớp khi không đủ sĩ số không, ai thông báo?
5. Có khảo sát hài lòng cuối khoá không? Kết quả dùng vào đâu?

## 8. Kế toán / thu học phí

1. Các khoản thu: phí hồ sơ, phí giữ chỗ, học phí, phí bán trú, đồng phục, khoá ngắn hạn… thu qua kênh nào?
2. Học bổng / ưu đãi được ghi nhận ở đâu, ai đối soát?
3. Kế toán cần biết gì từ CRM, và CRM cần biết gì từ kế toán? (Thường: "đã nộp cọc chưa" là trạng thái then chốt để đóng hồ sơ tuyển sinh.)
4. Chính sách hoàn phí? [ĐIỀN]
5. Phần mềm kế toán đang dùng? Có API / xuất file không?

## 9. IT / hệ thống

1. Hệ thống đang dùng: phần mềm quản lý trường học (SIS), kế toán, website (CMS), tổng đài, email, Zalo OA, LMS. Ai là nhà cung cấp, có API không?
2. Đăng nhập: Google Workspace / Microsoft 365? Có SSO không?
3. Chính sách bảo mật hiện có; ai được xem dữ liệu học sinh?
4. Ai sẽ là **admin CRM** phía trường sau go-live? (Nếu chưa có người → rủi ro lớn, ghi vào RAID.)
5. Tên miền gửi email đã cấu hình SPF/DKIM/DMARC chưa?
6. Có hạn chế về lưu trữ dữ liệu ở nước ngoài không? (Liên quan Nghị định 13/2023 và Luật BVDLCN — xem doc 05.)

## 10. Phụ huynh (tuỳ chọn, rất nên làm)

1. Lần đầu anh/chị biết đến trường qua đâu? Sau đó tìm hiểu thêm ở đâu?
2. Anh/chị đã cân nhắc những trường nào khác? Điều gì làm trường này khác biệt?
3. Trong quá trình tìm hiểu, có lúc nào anh/chị thấy khó chịu hoặc bị làm phiền không?
4. Ai trong gia đình quyết định cuối cùng? Con có tiếng nói đến đâu?
5. Anh/chị thích được liên lạc bằng kênh nào, giờ nào?

## 11. Mẫu tổng hợp sau discovery

Điền và gửi cho Sponsor **trước** kickoff ít nhất 5 ngày làm việc.

| Mục | Nội dung |
|---|---|
| Top 5 pain point (xếp theo tác động) | 1. … (nguồn: S3, S4) |
| Quy trình hiện tại (as-is) | Link sơ đồ |
| Số liệu nền (baseline) | Lead/năm, tỷ lệ chuyển đổi, speed-to-lead, show-up sự kiện — ghi rõ "đo" hay "ước tính" |
| Mâu thuẫn phát hiện được | Ví dụ: Marketing nói 4.000 lead, Tuyển sinh nói 2.500 — do định nghĩa "lead" khác nhau → đưa vào quyết định D-02 |
| Câu hỏi còn mở | Đưa vào agenda kickoff (doc 07) |
| Rủi ro sơ bộ | Đưa vào RAID (doc 08) |
